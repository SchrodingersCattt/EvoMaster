class ToolPlane(str, enum.Enum):

    ```python
    class StructuralValidation:
        """Layer A: 无状态参数/拓扑校验。"""

        def validate(
            self,
            runtime_topology: RuntimeTopology,
            tool_instance: ToolInstance,
            tool_args: dict[str, Any],
        ) -> ToolDecision:
    ```

    三步校验逻辑：
    1. **args_schema 校验**：如果 `tool_instance.tool_spec.args_schema` 非空 dict，使用 `jsonschema.validate(tool_args, schema)` 校验。捕获 `jsonschema.ValidationError`，将 `e.message` 作为 `ToolDecision(decision="deny", reason=f"Invalid arguments: {e.message}")` 返回。
    2. **plane 启用检查**：如果 `tool_instance.tool_binding.plane not in runtime_topology.active_planes`，返回 `ToolDecision(decision="deny", reason=f"Plane '{plane.value}' is not active in current topology")`。
    3. **session_capabilities 匹配**：如果 `runtime_topology.session_capabilities is not None`，检查以下映射关系：
       - tool_binding.plane == SESSION_SHELL 且 spec.capabilities 含 "shell.execute" → 需要 caps.shell_input == True
       - tool_binding.plane == SESSION_FS 且 file_ops == "sftp" 对于需要 "workspace.write" capability 的工具不阻止（Phase 1 不做细粒度 FS capability check）
       - 如果不匹配，返回 `ToolDecision(decision="deny", reason="Session does not support required capability: {cap}")`

    所有校验通过返回 `ToolDecision(decision="allow")`。

    Import 顺序：标准库 → 第三方(jsonschema) → 本地(matmaster.types.*)。
