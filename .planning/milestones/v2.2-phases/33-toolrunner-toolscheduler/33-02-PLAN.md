    **_RWLock 内部类**（~50 行）：
    ```python
    class _RWLock:
        """经典读写锁：shared_read 可并发，exclusive 互斥。"""
        def __init__(self) -> None:
            self._lock = asyncio.Lock()
            self._cond = asyncio.Condition(self._lock)
            self._readers: int = 0
            self._writer: bool = False
    ```

    方法：
    - `async def acquire_read(self, timeout: float) -> bool`: 在 `async with self._lock:` 内循环等待 `self._writer == False`，使用 `asyncio.wait_for(self._cond.wait(), timeout=remaining)` 处理超时。等待结束后 `self._readers += 1`，返回 True。超时返回 False。
    - `async def release_read(self) -> None`: `async with self._lock:` 内 `self._readers -= 1`，如果 readers == 0 则 `self._cond.notify_all()`。
    - `async def acquire_write(self, timeout: float) -> bool`: 在 `async with self._lock:` 内循环等待 `self._writer == False and self._readers == 0`，使用相同超时机制。等待结束后 `self._writer = True`，返回 True。超时返回 False。
    - `async def release_write(self) -> None`: `async with self._lock:` 内 `self._writer = False`，`self._cond.notify_all()`。

    超时计算使用 `asyncio.get_event_loop().time()` 计算 deadline，每次 wait 前计算 remaining = deadline - now。remaining <= 0 时直接返回 False。

    **SchedulerTicket** dataclass：
    ```python
    @dataclass
    class SchedulerTicket:
        """Scheduler 返回的资源持有凭证。"""
        resource_locks: list[tuple[str, str]]  # [(resource_id, mode), ...]
    ```

    **ToolScheduler**：
    ```python
    class ToolScheduler:
        def __init__(self, default_timeout: float = 60.0) -> None:
            self._default_timeout = default_timeout
            self._rw_locks: dict[str, _RWLock] = {}
            self._semaphores: dict[str, asyncio.Semaphore] = {}
    ```

    方法：
    - `_get_rw_lock(self, resource_id: str) -> _RWLock`: 惰性创建 per-resource_id 的 _RWLock。
    - `_get_semaphore(self, resource_id: str, limit: int) -> asyncio.Semaphore`: 惰性创建 per-resource_id 的 Semaphore。如果已存在则返回现有的。limit 为 None 时防御性处理为 1 并 log warning。
    - `async def acquire(self, claims: tuple[ResourceClaim, ...], timeout: float | None = None) -> SchedulerTicket | None`: 按顺序 acquire 每个 claim。任何一个 acquire 失败（超时）则 release 已 acquire 的资源，返回 None。全部成功返回 SchedulerTicket。
      - exclusive: `_get_rw_lock(c.resource_id).acquire_write(timeout)`
      - shared_read: `_get_rw_lock(c.resource_id).acquire_read(timeout)`
      - counted: `asyncio.wait_for(self._get_semaphore(c.resource_id, c.limit or 1).acquire(), timeout=timeout)`
    - `async def release(self, ticket: SchedulerTicket) -> None`: 按 ticket.resource_locks 逆序 release。
      - exclusive: `release_write()`
      - shared_read: `release_read()`
      - counted: `semaphore.release()`

    注意事项：
    - release 方法是 async（因为 _RWLock 内部 release 需要 async with self._lock）
    - acquire 中如果部分 claim 成功后某个 claim 超时，必须 rollback 已获取的资源（调用 release 对应方法）
    - 日志使用 `logging.getLogger(__name__)`
