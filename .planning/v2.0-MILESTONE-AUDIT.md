## Cross-Phase Integration

### Complete Flows (3/4)

**1. Main Agent Execution** (POST /stream)
`chat_api` -> `stream_service` -> `agent_run_service.run_agent_sync()` -> daemon thread `_loop` -> `run_coroutine_threadsafe(router.start())` -> `run_coroutine_threadsafe(exp.build_runtime())` -> `run_coroutine_threadsafe(kernel.run())` -> `async with provider` -> `async for chunk in chat_stream()` -> `await run_*()` hooks -> `bus.emit_nowait()` -> `asyncio.Queue` -> `EventRouter._consume_loop` -> `SSEHandler.handle()` -> SSE output

**2. SubAgent Spawn**
`Kernel` -> `await tool_registry.execute("spawn")` -> `SpawnTool.execute()` -> `await spawn_fn()` -> `await child_exp.run()` -> `await child_kernel.run()` (same event loop, no bridge needed)

**3. DevShell**
`DevRunner.run()` -> `asyncio.run(_run_once())` -> `await exp.build_runtime()` -> `await kernel.run()` -> `await exp._run_cleanup_callbacks()`

### Broken Flow (1/4)

**4. Confirmation Flow** (MITIGATED - disabled in production)
`POST /confirmation_reply` -> `stream_service` -> `ConfirmationHookAdapter.put_content()` -> `hook.resolve()` -> **AttributeError** (method doesn't exist in current ConfirmationHook)

**Root cause:** Phase 15-02 asyncio.Future implementation (commit 70521e2) was reverted during subsequent merge operations. Current `confirmation.py` uses old `queue.Queue.get()` blocking pattern.

**Mitigation:** ConfirmationHook is commented out in `agent_run_service.py` lines 440-443. No production traffic hits this path.
