**matmaster/core/exp.py -- _make_spawn_fn async 闭包（按 D-04）：**

当前 `_make_spawn_fn` (line 89-133) 返回 sync `spawn_fn` 内含 bridge loop。改造为：

1. 返回类型注解更新。当前：`Callable[[str, str, threading.Event | None], str]`。改为不标注返回类型（Python 无法简洁表达 async callable 返回类型），或用 `Any`。最简方案：删除返回类型注解，只保留参数签名。

2. 内部 `def spawn_fn(...)` 改为 `async def spawn_fn(...)`。

3. 移除 bridge loop（`_loop = asyncio.new_event_loop()` / `_loop.run_until_complete(...)` / `_loop.close()`），改为直接 await：

```python
@staticmethod
def _make_spawn_fn(
    ctx: PlaygroundContext,
    bus: MessageBus | None,
    source_prefix: str,
) -> Any:
    """Create async spawn_fn closure capturing parent runtime context.

    The returned async callable creates a child Exp from exp_name, runs it
    with the parent's PlaygroundContext and MessageBus, and returns the result.
    """

    async def spawn_fn(
        exp_name: str,
        task: str,
        stop_event: threading.Event | None = None,
    ) -> str:
        from matmaster.config.loader import load_exp_config

        child_config = load_exp_config(exp_name)
        child_exp = Exp(child_config)
        child_source = f"{source_prefix}:{exp_name}"
        child_spawn_id = uuid.uuid4().hex[:16]
        child_runtime = await child_exp.build_runtime(
            ctx,
            bus=bus,
            source_override=child_source,
            spawn_id=child_spawn_id,
        )
        try:
            run_result = await child_runtime.kernel.run(
                child_runtime.spec, task, stop_event=stop_event
            )
            result = run_result.result
            if result.status == "completed" and result.final_content:
                return result.final_content
            return f"SubAgent finished with status={result.status}, reason={result.reason}"
        finally:
            await child_exp._run_cleanup_callbacks()

    return spawn_fn
```

关键变化：
- `def spawn_fn` -> `async def spawn_fn`
- `child_exp.build_runtime(...)` -> `await child_exp.build_runtime(...)`
- `_loop.run_until_complete(child_runtime.kernel.run(...))` -> `await child_runtime.kernel.run(...)`
- `child_runtime.cleanup()` -> `await child_exp._run_cleanup_callbacks()`
- 删除 `_loop = asyncio.new_event_loop()` / `_loop.close()` / `try: ... finally: _loop.close()`

```python
async def execute(self, arguments: dict[str, Any]) -> str | ToolResult:
    """Override BuiltinTool.execute() for native async spawn.

    SpawnTool is the only BuiltinTool that needs native async execution
    (spawn_fn is async). Bypasses the base class to_thread(_execute) pattern.
    """
    if self._spawn_fn is None:
        return (
            "Error: Spawn is not available in this context "
            "(recursion depth limit reached)"
        )

    exp_name = arguments.get("exp_name", "").strip()
    task = arguments.get("task", "").strip()

    if not exp_name or not task:
        return "Error: Both exp_name and task are required"

    try:
        return await self._spawn_fn(exp_name, task, self._stop_event)
    except Exception as e:
        self.logger.error("Tool %s failed: %s", self.name, e, exc_info=True)
        return f"Error: {e}"
```
