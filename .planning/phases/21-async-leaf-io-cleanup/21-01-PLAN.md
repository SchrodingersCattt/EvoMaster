<objective>
Close TOOL-02 (BashTool native async subprocess) and remove OpenAIProvider orphaned chat_with_retry.

Purpose: BashTool's session-free path (matmaster LocalSession) currently runs subprocess.run inside asyncio.to_thread, occupying a thread pool slot unnecessarily. Switching to asyncio.create_subprocess_exec eliminates this overhead. The chat_with_retry method was removed from the LLMProvider Protocol in Phase 12 but its implementation was left orphaned in OpenAIProvider -- zero production callers remain.

Output: BashTool with dual-path execute() (native async vs to_thread bridge), OpenAIProvider without dead code, updated tests for both.
</objective>
