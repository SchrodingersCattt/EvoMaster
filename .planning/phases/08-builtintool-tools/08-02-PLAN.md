       - `__init__(self, workdir: Path)`: self._path = workdir / ".tasks.json"
       - 类级别 `_lock = threading.Lock()` 保护并发读写（per RESEARCH Pitfall 2）
       - `_read()`: 文件不存在返回 {"tasks": {}}，存在则 json.loads
       - `_write(data)`: json.dumps(data, indent=2, ensure_ascii=False) 写入文件
       - `create(description: str) -> dict`: 生成 uuid4()[:8] 作为 id，status="open"，created_at/updated_at 为 UTC ISO8601
       - `get(task_id: str) -> dict | None`: 返回 task 或 None
       - `list_all() -> list[dict]`: 返回所有 task 的 list
       - `update(task_id: str, **fields) -> dict | None`: 仅接受 description/status 字段，更新 updated_at
       - `complete(task_id: str) -> dict | None`: 调用 update(task_id, status="completed")
       - 所有修改方法都在 `with self._lock:` 块内执行

    3. 创建 5 个 TaskTool 文件，每个继承 BuiltinTool：

       task_create.py -- TaskCreateTool:
       - name = "task_create"
       - json_schema: properties 包含 description(required, string)
       - _execute: 检查 self._workdir，创建 TaskStore(self._workdir)，调用 store.create(arguments["description"])，返回 json.dumps(task)

       task_get.py -- TaskGetTool:
       - name = "task_get"
       - json_schema: properties 包含 task_id(required, string)
       - _execute: store.get(task_id)，None 时返回 f"Task not found: {task_id}"

       task_list.py -- TaskListTool:
       - name = "task_list"
       - json_schema: 无 required properties（列出所有任务）
       - _execute: store.list_all()，返回 json.dumps(tasks)

       task_update.py -- TaskUpdateTool:
       - name = "task_update"
       - json_schema: properties 包含 task_id(required)、description(optional)、status(optional, enum ["open","in_progress","completed"])
       - _execute: 提取 description/status 字段传入 store.update()

       task_complete.py -- TaskCompleteTool:
       - name = "task_complete"
       - json_schema: properties 包含 task_id(required, string)
       - _execute: store.complete(task_id)
