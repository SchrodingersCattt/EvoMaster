**Part A: 7 个 run_* helpers async 化 (matmaster/core/hooks.py)**

将以下 7 个函数全部从 `def` 改为 `async def`，内部所有 hook 方法调用加 `await`：

1. `run_pre_tool_call` -- intercepting, 短路语义保持：
```python
async def run_pre_tool_call(hooks: list[Hook], tool_call: ToolCallData) -> HookAction:
    for hook in hooks:
        action = await hook.pre_tool_call(tool_call)
        if action == HookAction.SKIP:
            return HookAction.SKIP
    return HookAction.CONTINUE
```

2. `run_should_continue` -- intercepting, 短路语义保持：
```python
async def run_should_continue(hooks: list[Hook], messages: list[Message], turn: int) -> bool:
    for hook in hooks:
        if not await hook.should_continue(messages, turn):
            return False
    return True
```

3. `run_pre_llm_call` -- observation, 无短路：
```python
async def run_pre_llm_call(hooks: list[Hook], messages: list[Message], turn: int) -> None:
    for hook in hooks:
        await hook.pre_llm_call(messages, turn)
```

4. `run_post_tool_call` -- observation, 无短路：
```python
async def run_post_tool_call(hooks: list[Hook], tool_call: ToolCallData, result: ToolResult) -> None:
    for hook in hooks:
        await hook.post_tool_call(tool_call, result)
```

5. `run_on_stream_chunk` -- observation, 无短路：
```python
async def run_on_stream_chunk(hooks: list[Hook], chunk: StreamChunk) -> None:
    for hook in hooks:
        await hook.on_stream_chunk(chunk)
```

6. `run_on_segment_complete` -- observation, 保留 getattr 向后兼容但 await 返回值：
```python
async def run_on_segment_complete(
    hooks: list[Hook], segment_type: str, content: str, stream_id: str | None
) -> None:
    for hook in hooks:
        fn = getattr(hook, "on_segment_complete", None)
        if fn is not None:
            await fn(segment_type, content, stream_id)
```

7. `run_guard_blocked` -- observation, 保留 getattr 向后兼容但 await 返回值：
```python
async def run_guard_blocked(
    hooks: list[Hook], tool_call: ToolCallData, result: GuardResult

    for hook in hooks:
        fn = getattr(hook, "on_guard_blocked", None)
        if fn is not None:
            await fn(tool_call, result)
```
