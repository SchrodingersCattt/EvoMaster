    Add asyncio bridge loops to FOUR call sites. All bridges are inline patterns (no shared utility module per D-05). The bridge template is:

    ```python
    _loop = asyncio.new_event_loop()
    try:
        result = _loop.run_until_complete(kernel.run(...))
    finally:
        _loop.close()
        # ... sync cleanup ...
    ```

    CRITICAL ordering in finally: `_loop.close()` BEFORE any `runtime.cleanup()` call. Reason: the event loop holds references to async resources (provider connections, MCP sessions) that need orderly shutdown within the loop's context. After `_loop.close()`, sync cleanup code runs independently. `runtime.cleanup()` itself is sync (calls `_run_cleanup_callbacks` which is sync), so it does not need the loop.
