    FullToolRunner 类实现（per D-01, D-05, D-06, D-08）：

    ```python
    class FullToolRunner:
        """完整 ToolRunner: Catalog -> Validation -> Guard -> Policy -> Scheduler -> Execute -> Release.

        Per D-01: 不调用 pre_hook/post_hook。
        Per D-05: 严格遵循 spec section 9.1 执行链。
        Per D-06: 每层统一产出 ToolResult，meta["layer"] 标记失败来源。
        """

        def __init__(
            self,
            catalog: ToolCatalog,
            structural_validation: StructuralValidation,
            guard_pipeline: GuardPipeline,
            capability_policy: CapabilityPolicy,
            scheduler: ToolScheduler,
            topology: RuntimeTopology,
        ) -> None:
            self._catalog = catalog
            self._validation = structural_validation
            self._guard_pipeline = guard_pipeline
            self._policy = capability_policy
            self._scheduler = scheduler
            self._topology = topology
    ```

    execute_batch 方法逻辑（per D-05 串行处理每个 tool_call 的完整链路）：

    对每个 tool_call (tc) 依次执行：

    1. **Cancel check**: `if ctx.stop_event and ctx.stop_event.is_set()` -> `ToolResult(status="cancelled", content="Run cancelled.")`，append 并 continue。

    2. **Catalog lookup**: `instance = self._catalog.get_tool(tc.name)`。如果 None -> `ToolResult(status="error", content=f"Unknown tool: {tc.name}", meta={"layer": "catalog"})`，append + on_result + continue。

    3. **StructuralValidation (Layer A)**: `decision = self._validation.validate(self._topology, instance, tc.arguments)`。如果 deny -> `ToolResult(status="error", content=decision.reason, meta={"layer": "structural"})`，append + on_result + continue。

    4. **RunStateGuard (Layer B)**: `guard_result = self._guard_pipeline.evaluate(tc, ctx.turn, ctx.max_turns)`。如果 not allowed -> `ToolResult(status="error", content=guard_result.reason or "Guard denied", meta={"layer": "guard"})`，append + on_result + continue。

    5. **CapabilityPolicy (Layer C)**: `decision = self._policy.evaluate(self._topology, instance, tc.arguments)`。如果 deny -> `ToolResult(status="error", content=decision.reason, meta={"layer": "policy", "guidance": decision.guidance})`，append + on_result + continue。

    6. **Fast path check** (per D-08):
       ```python
       claims = instance.tool_binding.resource_claims
       is_fast = (
           instance.tool_spec.effect_level == "none"
           and all(c.mode == "shared_read" for c in claims)
           and instance.tool_spec.fast_path_eligible
       )
       ```

    7. **Scheduler acquire** (skip for fast path):
       ```python
       ticket: SchedulerTicket | None = None
       if not is_fast:
           ticket = await self._scheduler.acquire(claims, timeout=self._scheduler._default_timeout)
           if ticket is None:
               tr = ToolResult(status="error", content="Scheduling timeout", meta={"layer": "scheduler"})
               results.append((tc, tr))
               if on_result: await on_result(tc, tr)
               continue
       ```

    8. **Execute + Release**:
       ```python
       try:
           tr = await instance.tool_executor(tc.arguments)
       except Exception as e:
           tr = ToolResult.from_error(tc.name, e)
       finally:
           if ticket is not None:
               await self._scheduler.release(ticket)
       ```

       **CRITICAL: `self._scheduler.release()` 是 async 方法（ToolScheduler._RWLock 内部 release 需要 `async with self._lock`），finally 块中必须使用 `await self._scheduler.release(ticket)`。不 await 会导致协程被创建但不执行，资源永远不会释放。**

    9. Append (tc, tr) to results，call on_result if provided。

    返回 results list。
