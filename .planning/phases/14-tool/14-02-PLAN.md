**lazy_mcp.py LazyMCPTool 改造 (per D-05):**

lazy_mcp.py 已有 `import asyncio`（第 8 行）。将 LazyMCPTool.execute() 改为 async def，内部用 asyncio.to_thread 包装所有同步调用：

```python
async def execute(self, arguments: dict[str, Any]) -> ToolResult:
    if self._real_tool is None:
        self._real_tool = await asyncio.to_thread(
            self._connector.connect_and_get_tool,
            self._server_name, self._remote_tool_name,
        )
    args_json = json.dumps(arguments, ensure_ascii=False)
    observation, info = await asyncio.to_thread(
        self._real_tool.execute, self._connector.session, args_json,
    )
    content = (
        observation
        if isinstance(observation, str)
        else json.dumps(observation, ensure_ascii=False, default=str)
    )
    info_dict = info if isinstance(info, dict) else {}
    status = (
        "error"
        if "error" in info_dict or content.lstrip().startswith("Error:")
        else "success"
    )
    return ToolResult(status=status, content=content, info=info_dict)
```

注意：json.dumps 是纯 CPU 操作，不需要 to_thread。只有 connector.connect_and_get_tool 和 real_tool.execute 是同步 I/O 需要包装。
