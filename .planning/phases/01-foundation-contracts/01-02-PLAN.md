<objective>
Implement the synchronous MessageBus event system and QueueBridge SSE adapter. MessageBus provides a thread-safe queue for agent kernel to emit BusEvent objects. QueueBridge consumes events from MessageBus and converts them to the existing SSE payload dict format that stream_service.py expects.

Purpose: Decouples agent event emission from SSE transport. Agent kernel emits typed BusEvent objects to MessageBus; QueueBridge translates them to the existing callback-based SSE format, allowing the service layer to remain unchanged.
Output: matmaster/bus/ package with queue.py and bridge.py + comprehensive unit tests.
</objective>
