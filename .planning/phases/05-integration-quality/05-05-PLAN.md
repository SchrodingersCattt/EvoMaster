  <action>
    Create docs/migration-guide.md with the following sections:

    1. **Overview**: What was refactored (three-layer architecture: playground -> exp -> kernel),
       why (inheritance-driven to contract-driven), scope (mat_master + minimal only).

    2. **Architecture Changes**: Side-by-side comparison table:
       | Old | New | Change Type |
       |-----|-----|-------------|
       | StreamingMatMasterAgent | AgentKernel + Hook system | Replaced |
       | get_playground_class() factory | Playground(config_path) direct construction | Replaced |
       | evomaster.utils.TaskInstance | str + list[Message] | Replaced |
       | evomaster.utils.create_llm / LLMConfig | OpenAIProvider direct construction | Replaced |
       | event_callback closure (130 lines) | EventRouter + PersistenceHandler + SSEHandler + WorkspaceHandler | Decomposed |
       | playground.mat_master.ConfirmationManager | ConfirmationHook (Hook Protocol) | Replaced |
       | pg._create_exp() internal creation | DirectExp explicit construction | Externalized |

    3. **New Components**:
       - matmaster/engine/agent.py -- AgentKernel: pure execution loop
       - matmaster/types/ -- PlaygroundContext, AgentRuntimeSpec, BusEvent contracts
       - matmaster/assembly/ -- DirectExp, ToolRegistry, ContextBuilder
       - matmaster/hooks/ -- ConfirmationHook, OutputProcessorHook, SkillHitHook, AssistantStateHook
       - matmaster/integration/ -- EventRouter, PersistenceHandler, SSEHandler, WorkspaceHandler, BohriumSetupService
       - matmaster/bus/ -- MessageBus, QueueBridge
       - matmaster/playground/ -- Playground (unified, config-driven)

    4. **Pipeline Flow** (old vs new):
       Old: init_playground -> get_playground_class -> pg.setup() -> pg._create_exp() -> exp.run() -> event_callback
       New: Playground.prepare() -> Exp.assemble() -> Kernel.run() with EventRouter consuming events

    5. **Configuration Changes**:
       - Config YAML location unchanged: configs/mat_master/config.yaml, configs/minimal/config.yaml
       - No dynamic module import at startup -- YAML validation only
       - PlaygroundContext no longer carries MCP/Skill -- capability config passed to DirectExp constructor

    6. **Breaking Changes**:
       - evomaster.core.get_playground_class -- removed, use Playground directly
       - playground.mat_master.service.stream_agent -- removed, use AgentKernel
       - playground.mat_master.service.confirm -- removed, use ConfirmationHook
       - TaskInstance -- removed, pass task as str + history as list[Message]
       - event_callback signature -- removed, events flow through MessageBus -> EventRouter

    7. **Deprecation Notices**:
       - evomaster/ package: DeprecationWarning at import
       - playground/mat_master/ modules: retained on disk, no longer called from service layer

    8. **Out of Scope**:
       - x_master migration (raises ValueError in new pipeline)
       - PlannerExp rewrite (separate effort)
       - Old code deletion (deferred until migration stabilizes)
  </action>
