    SubAgentTool class inheriting BuiltinTool. Per D-01, schema is `execute({"exp_name": "...", "task": "..."})`.

    ```python
    class SubAgentTool(BuiltinTool):
        name: ClassVar[str] = "sub_agent"
        description: ClassVar[str] = (overview + usage bullets, Claude Code quality per Phase 10 standard, under 400 chars)
        json_schema: ClassVar[dict[str, Any]] = {
            "type": "object",
            "properties": {
                "exp_name": {
                    "type": "string",
                    "description": "Name of the sub-agent type to spawn (e.g. 'explore'). Must match an exp definition in matmaster/exps/.",
                },
                "task": {
                    "type": "string",
                    "description": "Task description for the sub-agent to execute. Include all necessary context -- the sub-agent has no access to your conversation history.",
                },
            },
            "required": ["exp_name", "task"],
        }
    ```

    Constructor extends BuiltinTool.__init__ with `spawn_fn: Callable[[str, str], str] | None = None`. Store as `self._spawn_fn`.

    **IMPORTANT for Plan 02 forward compatibility:** Plan 02 will evolve spawn_fn to a 3-arg signature `(exp_name, task, stop_event) -> str` and add a `_stop_event` attribute. To ensure Plan 01 tests survive this change, ALL test stubs for spawn_fn MUST use `unittest.mock.Mock(return_value="...")` instead of lambda. Mock accepts any number of args, so tests will not break when Plan 02 adds the third argument.

    `_execute(arguments)` logic:
    - If `self._spawn_fn is None`: return `"Error: SubAgent spawning is not available in this context (recursion depth limit reached)"`
    - Extract exp_name and task from arguments. If either is empty/missing: return `"Error: Both exp_name and task are required"`
    - Call `self._spawn_fn(exp_name, task)` and return result string
