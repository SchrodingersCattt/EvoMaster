ML_MRB2 = [integer] Default:
ML_MRB2 = 8 Description: This tag sets the number N_{R}^l (for all l ) of radial basis functions used to expand the angular descriptor within the machine learning force field method. The angular descriptor is constructed from _{i}^{(3)}(r,s,) = d{r} d{s} δ({r}·{s} - {cos}) Σ_{j=1}^{N_{a}} Σ_{k j}^{N_{a}} _{ik} (r{r}) _{ij} (s{s}), {where} _{ij}({r}) = f_{{cut}}(r_{ij}) g({r}-{r}_{ij}) and g({r}) is an approximation of the delta function. In practice, the continuous function above is transformed into a discrete set of numbers p_{nν l}^{i} by expanding it into a set of radial basis functions χ_{nl}(r) and Legendre polynomials P_{l}({cos}) (see this section for more details): _{i}^{(3)}(r,s,) = Σ_{l=1}^{L_{{max}}} Σ_{n=1}^{N^{l}_{{R}}}Σ_{ν=1}^{N^{l}_{{R}}} {2l+1{2}} p_{nν l}^{i}χ_{nl}(r)χ_{ν l}(s)P_{l}({cos}). The tag ML_MRB2 sets the number N_{R}^l of radial basis functions to use in this expansion. The same number is used for all l . Mind: The number of angular descriptor expansion coefficients p_{nν l}^{i} scales quadratically with N_{R}^l set by this tag. It also depends on ML_LMAX2 and the number of elements.
