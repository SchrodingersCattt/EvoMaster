Default:
PLUGINS/STRUCTURE = .False.

Description:
PLUGINS/STRUCTURE
calls the Python plugin for the structure interface for each ionic relaxation step
When
PLUGINS/STRUCTURE
=.TRUE., VASP calls the
structure
Python function at the end of each ionic relaxation step.
The primary use-case of this tag is to modify the structure based on the computed energy, force and stress tensor.
