Title: SPRING_R0
URL: https://vasp.at/wiki/SPRING_R0
============================================================
SPRING_R0 = [real (array)] Description: Position of the minimum for a harmonic bias potential. The parameter SPRING_R0 defines the position of the minimum ( _{0μ} ) for the harmonic bias potential of the following form: V(_1,,_{M_8}) = Σ_{μ=1}^{M}{1}{2}_{μ} (_{μ}(q)-_{0μ})^2, \; where the sum runs over all ( M_8 ) coordinates the potential acts upon ( _{μ}(q) ), which are defined in the ICONST file by setting the status=8 . The units of _{0μ} correspond to units of the coordinate the potential acts upon (e.g., {} for coordinates with flag R, rad. for coordinates with flag A, dimensionless for coordinates with flag W, etc...). The number of items defined via SPRING_R0 must be equal to M_8 , otherwise the calculation terminates with an error message.
