Title: PROCAR_OPT
URL: https://vasp.at/wiki/PROCAR_OPT
============================================================
The
PROCAR_OPT file contains the spd- and site-projected wave function character at the k
points of the
KPOINTS_OPT driver. It is written whenever the
KPOINTS_OPT driver is active, i.e., when a
KPOINTS_OPT file is present or
KSPACING_OPT is set in the
INCAR file, and
LORBIT >= 10 or all
RWIGS values are positive.
The
PROCAR_OPT file has the same format as
PROCAR
; see that page for a detailed description.
