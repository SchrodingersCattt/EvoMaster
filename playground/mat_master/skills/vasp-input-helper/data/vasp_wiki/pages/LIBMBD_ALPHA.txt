Title: LIBMBD_ALPHA
URL: https://vasp.at/wiki/LIBMBD_ALPHA
============================================================
LIBMBD_ALPHA = [real array] Description: LIBMBD_ALPHA defines the free-atom polarizabilities α_{0} (bohr ^{3} ) used in the Tkatchenko-Scheffler and Many-body dispersion energy methods as implemented in the library libMBD of many-body dispersion methods

.
LIBMBD_ALPHA allows to set values for the free-atom polarizabilities
α_{0}
(bohr
^{3}
) used in the
Tkatchenko-Scheffler
and
Many-body dispersion energy
methods as implemented in the library libMBD of many-body dispersion methods

. For each atom listed in the
POSCAR file, a value has to be provided. The values are internally passed to the first column of the libMBD input
free_values
described at the page

.
Important:
This feature is available from VASP.6.4.3 onwards that needs to be compiled with
-DLIBMBD
.
libMBD is a separate library package that has to be downloaded

and compiled before VASP is compiled with the corresponding
precompiler options
and
links to the libraries
.
