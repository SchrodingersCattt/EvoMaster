Title: SDFTD3_DAMPING
URL: https://vasp.at/wiki/SDFTD3_DAMPING
============================================================
SDFTD3_DAMPING = zero | rational | mzero | mrational | optimizedpower Description: SDFTD3_DAMPING sets the type of damping function in the DFT-D3 method implemented in the simple-DFT-D3 package. SDFTD3_DAMPING allows to set the type of damping function to be used in the DFT-D3 method implemented in the simple-DFT-D3 package (
IVDW =15). The available damping functions are
SDFTD3_DAMPING =zero,

rational,

mzero,

mrational,

and optimizedpower.

Mind:
The
SDFTD3_DAMPING tag is available from VASP.6.6.0 onwards.
The
SDFTD3_DAMPING can be used only for the
simple-DFT-D3
package (
