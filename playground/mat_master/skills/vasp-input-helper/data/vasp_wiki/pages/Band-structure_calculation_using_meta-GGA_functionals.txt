Title: Band-structure calculation using meta-GGA functionals
URL: https://vasp.at/wiki/Band-structure_calculation_using_meta-GGA_functionals
============================================================
For
band-structure calculations
with
METAGGA functionals, follow the same procedure as for
band-structure calculations using hybrid functionals
. The reason is that a regular k mesh has to be provided in order to compute the kinetic-energy density.
