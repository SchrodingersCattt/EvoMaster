# L4_Q01 Open Problem Context

This local context file is intentionally lightweight but structured enough for
visionary-prompt grounding and consistency checks.

## Baseline constraints

- Keep proposals non-actionable for harmful synthesis or weaponization.
- Explicitly state at least one **changed premise** versus baseline theory.
- Tie claims to measurable observables (energy release profile, trigger barrier,

1. Premise change statement
2. Observable-shift prediction (with direction and approximate magnitude)
3. Falsification path (calculation + experiment or two independent calculations)
4. Resource estimate (coarse order of computational/experimental cost)
