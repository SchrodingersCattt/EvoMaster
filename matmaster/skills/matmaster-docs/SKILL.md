# Matmaster Docs

## 页面介绍

用户登陆MatMaster网页进入工作区，可以在左侧查看会话历史与项目文件，在中间对话区域与你进行对话交互，在右上角打开文件任务面板，查看工具调用trace（第一个tab），提交的Bohrium_job（第二个tab），云端文件系统（第三个tab）。

### 主页面

MatMaster 的产品界面围绕科研任务执行过程展开：
- 导航栏：左侧图标列，切换 Project、返回 Bohrium 平台
- 会话历史：按工作目录分组的会话列表，支持新建对话、搜索、删除
- 对话内容区：Agent 回复展示区，支持 Markdown 渲染、表格、代码块、文件链接、图表
- 消息输入区：用户输入框，支持模式切换（Direct/Planner）、附件上传、停止生成
- 文件/任务面板：右侧面板，展示当前会话的计算任务状态和工作目录文件列表，支持文件预览/下载
- 顶部工具栏：显示当前 Project 名称、分享按钮、设置入口

### 执行区域

该页面用于查看 Agent 的运行轨迹。用户可以按全部、失败、成功等条件筛选执行记录，观察 Agent 在任务执行过程中调用了哪些工具、每一步的执行状态，以及整体流程的推进情况。点击右侧跳转按钮，还可以进入对应步骤查看更详细的执行内容，用于排查问题、复盘流程或理解 Agent 的工作路径。

### 云端文件系统

云端文件系统用于管理当前 Project 下的共享文件，用于存放计算输入文件、运行结果。路径定位框支持输入路径，并可通过 `Tab` 补全、`Enter` 定位到指定目录；右上角工具按钮可用于新建、刷新等文件管理操作。用户通过自然语言发起任务，MatMaster 在同一工作区中完成对话、文件管理、任务执行和结果回收。默认的存储空间为10GB，存储空间可以在 https://www.bohrium.com/settings/storage 扩容。

### 设置页面

可以在左下角展开用户设置页面，包含当前额度、算力项目余额、个性化设置等。

## 计费系统

Matmaster产品采用额度，算力双轨道计费模式：
- 额度计费：用户与Matmaster交谈对话会消耗额度，对话内容越长，额度消耗越多；不同模型消耗额度的速率也不同，根据估算，快速/标准/旗舰模型消耗速率的比例约为1/4/10；额度会每周进行刷新，如果额度用完，暂时没有充值渠道，有特殊需求请联系 `materials@dp.tech`。
- 算力计费：Matmaster会通过Bohrium平台提交HPC任务，这些任务按照提交的机器型号和时间进行计费，并扣除用户的项目余额。机型价格由平台动态调整，不要凭记忆报价：当用户询问机型规格或价格时，调用 `Bohrium` 工具的 `list_machines` action 获取实时机型列表（`machine_type` 按需选 `cpu` 或 `gpu`，可用 `keyword` 过滤规格名），返回结果中的 `price` 字段（形如 `0.40 RMB/h`）即为计费单价，整理成表格回复用户即可。

## 文件支持

MatMaster 支持在对话中上传文件，直接看图、读取数据、处理你科研工作中的各类文件；同时内置在线预览，常见结果文件无需下载即可查看，科研结构文件还能直接做 3D 交互查看。

### 上传文件的方式

在对话输入框，你可以通过三种方式添加文件：

1. **点击上传**：点输入框的上传按钮，在文件选择器中选择一个或多个文件。
2. **拖拽上传**：把文件从桌面直接拖到输入框区域。
3. **粘贴上传**：复制图片后在输入框按粘贴，适合快速贴截图。

如果你希望把文件放进自己的工作区（个人空间或共享空间）反复使用，可在侧边存储区上传。存储区支持一次上传整个文件夹，并在传输列表中查看上传进度。

### 可上传的文件与限制

|文件用途|支持格式|大小限制|数量限制|
|---|---|---|---|
|普通附件|任意格式|单个不超过 100 MB|单条消息最多 10 个|
|图片（供 Matmaster 识图）|PNG、JPG / JPEG、WebP|单张不超过 3.5 MB|单条消息最多 5 张|

补充说明：
- GIF、BMP、HEIC、HEIF 等格式暂不进入图片视觉理解。
- TIFF / TIF 图片会作为普通附件发送，用于预览和留存，不参与 AI 识图。
- 让 Matmaster 识图需要切换到支持图片输入的模型；若当前模型不支持，系统会提示你更换。

### Matmaster 如何使用你上传的文件

- 图片：支持视觉的模型会直接读取图片内容，可用于识别图表、谱图、显微图像、结构示意图等。
- 普通附件：随消息一并提供给 Matmaster 作为参考资料。
- 工作区文件：Matmaster 可以读取你个人空间或共享空间中的文件，用于计算、分析并生成结果。

### 在线预览支持

无论是你上传的文件，还是 Matmaster 生成的结果文件，大多可以在预览面板中直接查看，无需下载：

|类型|说明|
|---|---|
|图片|PNG、JPG、GIF、WebP、SVG、BMP，支持缩放与拖动查看|
|PDF|内置阅读器直接翻页查看|
|Markdown|富文本渲染，支持 LaTeX 数学公式，可在线编辑|
|表格|CSV 以表格形式展示|
|代码与文本|语法高亮，覆盖 Python、C / C++、JavaScript / TypeScript、Shell、Rust、Go、Java、JSON、YAML、XML、LAMMPS 等；INCAR、INPUT、RUN.in 等计算输入文件也能识别|
|Office 文档|Word、Excel、PowerPoint 在线查看|
|网页|HTML 文件直接渲染|
|分子与晶体结构|3D 交互查看，支持 .cif、.xyz、.extxyz、.dump、.poscar、.gro、.mol、.mol2、.sdf 等，以及 POSCAR、CONTCAR、XDATCAR 这类无后缀的结构文件|
|流程图与图表|执行流程图、数据可视化图表内嵌展示|

### 暂不支持预览的情况

- 压缩包、可执行文件、音视频等二进制文件：无法在线预览，可下载后在本地打开。
- 超过 2 MB 的文本或 Markdown 文件：可以查看，但不支持在线编辑。
