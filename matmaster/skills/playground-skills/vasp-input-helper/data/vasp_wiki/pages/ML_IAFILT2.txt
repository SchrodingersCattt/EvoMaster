Title: ML_IAFILT2
URL: https://vasp.at/wiki/ML_IAFILT2
============================================================
ML_IAFILT2 = [integer] Default:
ML_IAFILT2 = 2 Description: This tag specifies the type of angular filtering used in the machine learning force field method. Fig. 1: Square of filtering function. This tag is only used if
ML_LAFILT2 = .TRUE. is set. Following cases are possible for the angular filtering function η (see also here ):
ML_IAFILT2 =1: The angular filtering function is described as η_{l}={1}{(2l+1)^{1/4}} .
ML_IAFILT2 =2: The angular filtering function

is described as
η_{l,a_{{FILT}}}={1}{1+a_{{FILT}} [l (l+1)]^{2}}
. Using this function the parameter
a_{{FILT}}
has to be defined too. It is set in the
INCAR file by setting
ML_AFILT2
. This option is the default.
In the case of the angular descriptor two radial basis functions are multiplied by each other (see
here
). Both basis functions use the same filtering function and hence the filtering is done by the square of the filtering function. This is plotted in Fig. 1 for the two different functions used for
ML_IAFILT2 =1 and 2 (labeled as TYPE1 and TYPE2, respectively). In the case of
ML_IAFILT2 =2 it can be seen that for the filtering parameter
ML_AFILT2 =0.002 and l =5 the function has only a contribution of 0.15. Using this filtering parameter the maximum cut-off for the angular quantum number can be reduced to
ML_LMAX2 =4. References ↑ J. P. Boyd, Chebyshev and Fourier Spectral Methods (Dover Publications, New York, 2000). Related tags and articles ML_LMLFF , ML_LAFILT2 , ML_AFILT2
