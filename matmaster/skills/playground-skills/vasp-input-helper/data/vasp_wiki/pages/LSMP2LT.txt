Title: LSMP2LT
URL: https://vasp.at/wiki/LSMP2LT
============================================================
LSMP2LT = .FALSE. | .TRUE. Default:
LSMP2LT = .FALSE. Description: LSMP2LT selects a stochastic Laplace transformed MP2 algorithm. If
LSMP2LT =.TRUE. and
ALGO =ACFTDRK is set, a quartic scaling stochastic Laplace transformed MP2 algorithm is selected.

This tag should be used in combination with
KPAR to tweak parallelization as described in this
tutorial
.
