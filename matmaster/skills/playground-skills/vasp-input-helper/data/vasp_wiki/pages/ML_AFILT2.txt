ML_AFILT2 = [real] Default:
ML_AFILT2 = 0.002 Description: This tag sets the filtering parameter for the angular filtering for ML_IAFILT2 in the machine learning force field method. This tag is only used if
ML_LAFILT2 = .TRUE. and
ML_IAFILT2 =2 are used. The angular filtering function

for
ML_IAFILT2 =2 is described as η_{l,a_{{FILT}}}={1}{1+a_{{FILT}} [l (l+1)]^{2}} . The tag ML_AFILT2 sets the parameter a_{{FILT}} . References ↑ J. P. Boyd, Chebyshev and Fourier Spectral Methods (Dover Publications, New York, 2000). Related tags and articles ML_LMLFF , ML_LAFILT2 , ML_IAFILT2
