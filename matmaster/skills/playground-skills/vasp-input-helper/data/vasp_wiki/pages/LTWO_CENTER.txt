LTWO_CENTER = [logical] Default:
LTWO_CENTER = .FALSE. Description: LTWO_CENTER calculates off-center Coulomb integrals . When chosen, the system calculates two types of integrals: Bare integrals (stored in VRijkl ) V_{ijkl}^{σσ'} = ∫ { d}{ r}∫ { d}{ r}' {w_{i}^{*σ}({ r}) w_{j}^{σ}({ r}) w_{k}^{*σ'}({ r}'+{ R}) w_{l}^{σ'}({ r}'+{ R})}{|{ r}-{ r}'|} Effectively screened integrals (stored in URijkl ) U_{ijkl}^{σσ'} = ∫ { d}{ r}∫ { d}{ r}' w_{i}^{*σ}({ r}) w_{j}^{σ}({ r}) U({ r},{ r}',ω) w_{k}^{*σ'}({ r}'+{ R}) w_{l}^{σ'}({ r}'+{ R}) When chosen, cRPA matrix elements in vaspout.h5 can be used with py4vasp to analyze the spatial decay of the Coulomb interaction using the Ohno potential

U(R) = {U(R=0)}{{Rδ + 1}}
