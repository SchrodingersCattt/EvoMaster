Title: VDW_BETA
URL: https://vasp.at/wiki/VDW_BETA
============================================================
VDW_BETA = [real] Description: VDW_BETA sets the offset for the damping radius or the power for the zero-damping component in the DFT-D3 methods implemented in the simple-DFT-D3 package. Mind: Available as of VASP 6.6.0 VDW_BETA allows to set the value of a parameter in the following versions of DFT-D3 (only available in the simple-DFT-D3 package): Offset β for the damping radius in the modified zero-damping function (
IVDW =15 with
SDFTD3_DAMPING =mzero). Power β for the zero-damping component in the optimized-power damping function (
IVDW =15 with
SDFTD3_DAMPING =optimizedpower). Note that β-6 corresponds to the values of β reported in Ref.

.
