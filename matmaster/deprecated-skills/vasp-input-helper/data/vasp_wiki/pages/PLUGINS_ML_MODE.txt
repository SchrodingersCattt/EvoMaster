Title: PLUGINS/ML MODE
URL: https://vasp.at/wiki/PLUGINS/ML_MODE
============================================================
PLUGINS/ML_MODE = none | run

Default:
PLUGINS/ML_MODE = none

Description: String-based tag selecting operation mode for running
PLUGINS/FORCE_AND_STRESS
plugins.
PLUGINS/ML_MODE = none
Forces and stress provided by the plugin are added to the ab-initio forces computed by VASP.
PLUGINS/ML_MODE = run
VASP skips the ab-initio calculation and uses the forces and stress of the plugin to replace the forces of VASP.
