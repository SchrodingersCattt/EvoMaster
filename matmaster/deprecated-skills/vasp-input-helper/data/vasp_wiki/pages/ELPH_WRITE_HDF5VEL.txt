Title: ELPH_WRITE_HDF5VEL
URL: https://vasp.at/wiki/ELPH_WRITE_HDF5VEL
============================================================
ELPH_WRITE_HDF5VEL = [logical] Default:
ELPH_WRITE_HDF5VEL = .FALSE. Description: If set, writes the electron group velocities to the vaspout.h5 file. Mind: Available as of VASP 6.5.0 The dataset is stored in the vaspout.h5 file $ h5ls -r vaspout.h5 | grep velocity /results/electron_phonon/electrons/velocity Dataset {3, 1, 20, 8} The group velocities are written in ev Å units in cartesian coordinates. This tag can be used independently of ELPH_WRITE_TEXTVEL . The number of bands is the one set by ELPH_NBANDS which can in some cases be different from NBANDS . If both are set, both outputs are written. Related tags and articles ELPH_RUN
