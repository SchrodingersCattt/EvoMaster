You might start a page on the INCAR-tag "tagname" as follows
{{TAGDEF|TAGNAME|val1 [{{!}} val2 {{!}} val3 {{!}} .. ] [|default] }}
Examples:
{{TAGDEF|NELM|[integer]}}
NELM = [integer] {{TAGDEF|NELM|[integer]|60}}
NELM = [integer] Default:
NELM = 60 {{TAGDEF|ISTART|0 {{!}} 1 {{!}} 2|0}}
ISTART = 0 | 1 | 2 Default:
ISTART = 0 When an INCAR-tag has more than one default (a conditional default) use the following construct {{TAGDEF|TAGNAME|val1 {{!}} val2 {{!}} val3}} {{DEF|TAGNAME|default1|condition1|default2|condition2 [|default3|condition3] ... }}
TAGNAME = val1 | val2 | val3 Default:
TAGNAME = default1 condition1 = default2 condition2 = default3 condition3 for instance {{TAGDEF|ICHARG|0 {{!}} 1 {{!}} 2 {{!}} 4}} {{DEF|ICHARG|2|if {{TAG|ISTART}}{{=}}0|0|else}}
ICHARG = 0 | 1 | 2 | 4 Default:
ICHARG = 2 if
ISTART =0 = 0 else The TAGDEF template can harbor up to six "default|condition" combinations.
