Title: OFIELD_A
URL: https://vasp.at/wiki/OFIELD_A
============================================================
OFIELD_A = [real] Description: The tag OFIELD_A sets the desired order parameter Q_6 in the Interface pinning method. The bias potential in the Interface pinning method is written as U_{bias}({R}) = 2 (Q_6({R}) - A)^2 . The tag OFIELD_A sets the desired value of the order parameter A . Related tags and articles Interface pinning , OFIELD_Q6_NEAR , OFIELD_Q6_FAR , OFIELD_KAPPA
