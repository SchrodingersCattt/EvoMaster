Title: QPOINTS
URL: https://vasp.at/wiki/QPOINTS
============================================================
The
QPOINTS file specifies the ( q
points) used to sample the Brillouin zone.
This file is used in the context of phonon dispersion calculations.
The format is the same as the
KPOINTS file.
