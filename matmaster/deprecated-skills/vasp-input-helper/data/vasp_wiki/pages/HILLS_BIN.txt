Title: HILLS_BIN
URL: https://vasp.at/wiki/HILLS_BIN
============================================================
HILLS_BIN = [Integer] Default:
HILLS_BIN = NSW Description: HILLS_BIN sets the number of steps after which the bias potential is updated in a metadynamics run (in case VASP was compiled with -Dtbdyn ). In metadynamics (
MDALGO =11 | 21), the bias potential is given as V(t,) = h Σ_{i=1}^{ t/t_G } \{ -{|^{(t)-^{(i · t_G)}|^2}{2 w^2} \}}. Thre parameters ( HILLS_H , HILLS_W , and HILLS_BIN ) must be provided by the user. The number of steps after which the bias potential is updated is set by HILLS_BIN . Related tags and articles Metadynamics , HILLS_H , HILLS_W , HILLSPOT , MDALGO
