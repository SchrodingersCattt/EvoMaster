# Polymer Question Bank Draft

这个目录用于沉淀 **polymer / 聚合物计算评测题** 的真实课题原型。这里不再列宽泛方向，而是直接记录可以落成评测题的 **完整研究项目**。每个项目都尽量满足：

- 有明确材料体系和研究背景
- 包含从建模到结论的完整链路
- 中间至少跨过两种方法层级，如量化、MD、自由能、ML
- 最终可产出可打分的表格、图、排序或决策

## 通用评分维度

每个课题在正式 YAML 中都应至少覆盖下面几类评价指标：

- `correctness`: 关键数值、排序、趋势、拟合结果、是否复现核心结论
- `grounding`: 是否真的基于提供的数据、结构、脚本和计算结果得出结论，而不是凭常识编造
- `workflow_completeness`: 是否完成了建模、计算、分析、汇总和最终决策，而不是只做了其中一步
- `efficiency`: 是否避免无效重复计算、无关探索和明显错误的工作流
- `report_quality`: 最终报告是否给出表格、图、关键假设、失败案例和下一步建议

下面列的是建议优先落地的真实完整课题。

## 1. PEO-LiTFSI / PCL-LiTFSI / PTMC-LiTFSI 固态聚合物电解质筛选

**研究背景**

聚醚、聚碳酸酯和相关柔性聚合物是锂盐固态电解质中的经典路线。真实问题不是单纯比较谁配位更强，而是找出 **配位强度、链段运动、盐解离和离子迁移之间的平衡**。

**建议输入资产**

- 三类聚合物重复单元或 SMILES
- 固定锂盐 `LiTFSI`
- 若干盐浓度条件，例如 `EO/Li = 20, 12, 8`
- 低聚体初始结构
- 无定形链段或预平衡 MD 初始盒子
- 一小批文献整理值，用于最终对照

**完整任务链**

1. 建立低聚体和盐配位模型，识别主要配位位点。
2. 做量化计算，比较 `Li+` 与不同重复单元的配位能、局域电荷分布、最低能构型。
3. 构建无定形电解质模型并运行 MD，提取 `Li-O` RDF、配位数、MSD、扩散系数和链段运动特征。
4. 比较不同盐浓度下的迁移机制变化，例如 vehicle vs hopping 倾向。
5. 将量化和 MD 特征汇总，建立一个小型 ranking model 或经验加权模型。
6. 输出最终候选排序，并明确指出最值得实验验证的聚合物-盐浓度组合。

**核心交付物**

- 配位能对比表
- `Li-O` RDF 图和配位数统计
- 扩散系数与温度/浓度关系图
- 最终 shortlist 和机制解释

**建议评价指标**

- `Li+` 配位能相对排序是否正确
- `Li-O` 第一峰位置与配位数是否在参考容差内
- 扩散系数数量级和排序是否合理
- 是否识别“更强配位不一定更高迁移率”
- 最终 shortlist 是否与前面数据闭环

## 2. PM6 / PTB7-Th / D18 / P3HT 给体聚合物预筛选

**研究背景**

有机光伏和 OFET 里常见的早期筛选流程不是直接上器件，而是先比较给体聚合物的 **能级、带隙、平面性、构象无序和堆积倾向**。这是非常典型的“量化 + 构象采样 + 小模型排序”课题。

**建议输入资产**

- 四个给体聚合物的重复单元结构
- 固定受体背景，例如 `Y6` 或一个给定受体能级窗口
- dimer / trimer / tetramer 初始构型
- 若干代表性构象或预优化结果
- 一个小型历史数据表，记录文献中 PCE 或 mobility proxy

**完整任务链**

1. 为每个给体构建低聚体模型，并生成多个构象。
2. 做量化计算，得到 HOMO、LUMO、带隙、偶极矩、主链扭转角和共面性指标。
3. 通过 `1/n` 外推估计聚合物极限带隙或 HOMO 趋势。
4. 用短程 MD 或构象采样分析链刚性、构象分布和可能的堆积倾向。
5. 将电子结构和构象特征汇总成小型 ranking model，输出候选优先级。
6. 给出“适合作为高电压候选”、“适合作为高吸收候选”或“综合最优候选”的结论。

**核心交付物**

- HOMO/LUMO/带隙汇总表
- 扭转角与平面性统计图
- 带隙外推图
- 给体 shortlist 与推荐理由

**建议评价指标**

- HOMO/LUMO 排序是否与参考一致
- 带隙外推值相对误差是否在容差内
- 是否正确识别高平面性与较强堆积倾向的关联
- 最终 shortlist 是否能被电子结构和构象数据支持
- 是否避免直接用文献器件效率替代计算判断

## 3. PIM-1 / Matrimid / 6FDA-DAM 气体分离膜性能对比

**研究背景**

气体分离膜研究的关键不只是单个扩散系数，而是 **溶解度、扩散性、自由体积和最终渗透率/选择性** 的联合分析。PIM-1、Matrimid、6FDA 系聚酰亚胺都是公开研究中高频出现的真实体系。

**建议输入资产**

- 三种聚合物的重复单元和链模型
- `CO2/N2` 或 `CO2/CH4` 的溶解/扩散原始数据或轨迹
- 自由体积分析脚本或中间文件
- 若干文献 benchmark 值

**完整任务链**

1. 建立聚合物无定形模型或读取给定膜结构。
2. 用量化或经验方法评估气体与局域官能团的相互作用强度。
3. 基于 MD 或给定轨迹提取溶解度、扩散系数、自由体积分布和局域滞留位点。
4. 计算 permeability 和 selectivity，并比较不同膜的 trade-off。
5. 基于结构描述符建立一个简化 surrogate，解释哪些特征主导分离性能。
6. 给出最适合 `CO2/N2` 或 `CO2/CH4` 分离的候选。

**核心交付物**

- 溶解度、扩散系数、渗透率、选择性总表
- 自由体积和局域吸附位点分析图
- trade-off 对比图
- 膜材料推荐结论

**建议评价指标**

- permeability / selectivity 计算是否正确
- 是否区分“高溶解度驱动”和“高扩散驱动”两类优势
- 是否能把自由体积、极性和刚性与性能关联起来
- 最终推荐是否与指标和 trade-off 一致

## 4. PS-PMMA 无规共聚体系的 Tg 与模量联合预测

**研究背景**

真实聚合物研发经常需要在组成空间里寻找兼顾高 `Tg` 和可接受模量的配方。`PS-PMMA` 无规共聚体系既真实又容易获得实验/模拟参考，是非常适合做 **MD + ML 联合建模** 的课题。

**建议输入资产**

- 不同 `PS:PMMA` 摩尔比的重复单元或链模型
- 多温度下的体积-温度、密度-温度数据
- 拉伸或弹性相关中间数据
- 一小批实验 `Tg` 与模量参考值

**完整任务链**

1. 建立多个组成点的聚合物模型。
2. 用 MD 提取体积-温度曲线，做分段拟合得到 `Tg`。
3. 提取密度、自由体积、链柔性和局域相互作用等中间描述符。
4. 构建回归模型预测 `Tg` 和模量，并检查模型对组成外推是否稳定。
5. 输出最佳组成窗口，并解释为什么某些区间更优。

**核心交付物**

- `Tg` 拟合图
- 组成-性质关系图
- `Tg` / 模量预测模型结果表
- 最佳组成建议

**建议评价指标**

- `Tg` 提取误差是否在容差内
- 模量预测的 `MAE/RMSE` 是否达到目标
- 是否识别组成变化带来的非线性趋势
- 是否明确指出模型不可可信的外推区间

## 5. PEO-LiTFSI 粘度-电导率窗口研究

**研究背景**

电解质和聚合物浆料研究中，粘度不是越低越好。真实问题通常是寻找 **既能加工、又不牺牲传输性能** 的温度和浓度窗口。PEO-LiTFSI 是非常常见、也适合做多尺度分析的实际体系。

**建议输入资产**

- PEO-LiTFSI 不同盐浓度模型
- 多温度 NEMD 或应力自相关数据
- 扩散/电导相关中间结果
- 粘度或流变参考曲线

**完整任务链**

1. 建立不同盐浓度和温度的体系。
2. 用量化方法或局域结构分析评估盐引起的配位和交联式束缚效应。
3. 用平衡 MD 或 NEMD 提取粘度、应力松弛和剪切变稀趋势。
4. 同时比较扩散系数或离子电导 proxy，构建性能-可加工性 trade-off。
5. 输出推荐的盐浓度和加工温度窗口。

**核心交付物**

- 粘度-温度曲线
- 粘度-电导率 trade-off 图
- 最佳加工窗口建议
- 对增粘机制的说明

**建议评价指标**

- 零剪切粘度和相对排序是否正确
- 是否识别牛顿区、非牛顿区或剪切变稀起始区间
- 是否识别盐浓度升高导致的迁移-粘度 trade-off
- 最终工艺窗口是否由数据支撑

## 6. 聚酰亚胺 / 氧化石墨烯界面粘附与取向研究

**研究背景**

聚酰亚胺-石墨烯氧化物界面是复合膜和增强材料里的真实问题。关键不只是一个吸附能，而是 **界面官能团、链取向、接触面积和粘附功** 如何共同决定界面稳定性。

**建议输入资产**

- 聚酰亚胺重复单元或短链模型
- 不同氧化度的 GO 表面模型
- 界面初始构型
- 短程量化优化结构
- MD 轨迹或可复现实验脚本

**完整任务链**

1. 构建不同氧化度和官能团分布的 GO 表面。
2. 用量化方法评估聚酰亚胺片段与表面官能团的吸附能和局域电荷重排。
3. 用 MD 追踪界面密度分布、链取向、接触面积和吸附寿命。
4. 计算界面粘附功、剥离趋势或润湿倾向。
5. 输出最优表面化学条件，并说明界面增强机制。

**核心交付物**

- 吸附能汇总表
- 界面密度/取向分析图
- 粘附功对比图
- 表面改性建议

**建议评价指标**

- 吸附能和粘附功排序是否正确
- 是否识别羟基/环氧/羧基等官能团的不同作用
- 是否能把链取向和宏观粘附联系起来
- 最终表面改性建议是否自洽

## 7. PEO-LiTFSI 中 Li+ 迁移 PMF 与 hopping 机制分析

**研究背景**

很多聚合物电解质研究真正的控制因素不是平均配位结构，而是 **Li+ 从一个配位位点跳到另一个位点时的自由能垒**。这类课题非常适合用 umbrella sampling 或 metadynamics 构造真实、可打分的 PMF 任务。

**建议输入资产**

- PEO-LiTFSI 代表性局域结构
- 反应坐标定义，如 `Li-O` 距离或位点间投影坐标
- umbrella sampling 窗口或预生成轨迹
- 参考 PMF 曲线和 barrier 值

**完整任务链**

1. 明确反应坐标并构建初始配位态。
2. 用量化或局域结构分析确认起点、终点和中间态的化学意义。
3. 运行 umbrella sampling / WHAM 或读取预生成轨迹，重建 PMF。
4. 提取自由能最低点、跃迁态位置和主能垒。
5. 将自由能信息与常规 MD 中的配位数、RDF 和扩散趋势对照解释。
6. 输出迁移机制判断，并说明为什么某些条件下 hopping 更容易发生。

**核心交付物**

- PMF 曲线
- barrier 与中间态表
- 迁移机制示意说明
- 与扩散数据的对照分析

**建议评价指标**

- PMF 主能垒数值是否在容差内
- 最低点和过渡态位置是否识别正确
- 是否正确解释 reaction coordinate
- 是否能把 PMF 与扩散/配位行为闭环起来
